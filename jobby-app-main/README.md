# Jobby App

A responsive job portal web application built with React.js. Users can log in, search for jobs, apply filters, and view detailed job information.

## Features

- JWT based login and protected routes
- Search jobs by title or keyword
- Filter by employment type and salary range
- View detailed job information and similar jobs
- User profile fetched from API
- Error handling and loading states for all API calls
- Fully responsive on mobile and desktop

## Tech Stack

- React.js
- JavaScript
- CSS3 and Flexbox
- React Router
- REST APIs
- JWT Authentication
- js-cookie
